# Examples

Generated by `npm run examples` from the sample inputs in
[`src/lib/defaultText.ts`](../src/lib/defaultText.ts). Each file shows one messy
input and what CleanMath produces in all three delimiter modes.

- [Classic LLM answer](01-llm-classic.md) - Mixed delimiters, a redundant $$ around align, a missing row break
- [Korean study notes](02-korean-notes.md) - Hangul prose inside math blocks, plus smuggled zero-width spaces
- [Unicode + matrices](03-unicode-soup.md) - Matrix rows missing their row breaks
- [Truncated answer](04-broken.md) - Unclosed $$ and \( - see the safety net catch them
- [Spacing + escapes](05-spacing.md) - Bare sin, dx with no thin space, glued \text{}, x**2 and JSON-escaped \\frac
- [Research report (.tex)](06-report.md) - A whole LaTeX paper: macros, numbered equations, theorems, a table - open Live Preview
